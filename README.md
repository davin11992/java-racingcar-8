# java-racingcar-precourse

## 🚗 기능 목록

### 입력 기능

- 경주할 자동차 이름을 입력받는다.
    - 자동차 이름은 쉼표(`,`)로 구분한다.
    - 각 이름은 5자 이하여야 한다. (유효하지 않으면 예외 발생)
- 시도할 라운드 횟수를 입력받는다.

### 출력 기능

- 각 라운드별 실행 결과를 출력한다.
    - 전진한 자동차는 `-`로 표시한다.
- 최종 우승자를 출력한다.
    - 공동 우승일 경우 쉼표(`,`)로 구분하여 출력한다.

### 자동차 관련 기능

- 입력받은 이름들을 바탕으로 자동차 객체 리스트를 생성한다.
- 각 자동차는 이름과 전진 횟수를 멤버 변수로 가진다.

### 전진 로직

- 0 ~ 9 사이의 랜덤 값을 생성한다.
- 4 이상이면 전진한다. (전진 시 전진 횟수 +1)

### 우승자 구하기

- 가장 많이 전진한 자동차(들)를 우승자로 결정한다.
