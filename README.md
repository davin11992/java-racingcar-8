# java-racingcar-precourse

🚗 입력받은 자동차들이 라운드별로 경주를 하고, 우승자를 출력하는 프로그램입니다.

---

## 🧩 기능 목록

### 사용자 입력 (InputView)

- `Console.readLine()`으로 입력을 한 줄 단위로 받습니다.
- **자동차 이름 입력**
    - 입력 문구: `경주할 자동차 이름을 입력하세요.(이름은 쉼표(,) 기준으로 구분)`
    - 쉼표(`,`)로 구분된 자동차 이름들을 받습니다.
    - 빈 입력은 `IllegalArgumentException` 발생합니다.
- **시도 횟수 입력**
    - 입력 문구: `시도할 횟수는 몇 회인가요?`
    - 빈 입력은 `IllegalArgumentException` 발생합니다.

---

### 입력 검증 (InputValidator)

- 시도 횟수 입력값이 자연수 형태(`\\d+`)인지 확인합니다.
- 입력값이 자연수가 아니면 예외가 발생합니다.
- 정적 유틸 클래스 형태로 인스턴스화를 방지하였습니다.

---

### 자동차 객체 생성 (Car, Cars)

- `Car`
    - 자동차 이름과 현재 위치(`position`)를 가집니다.
    - 이름 검증 : null, 공백, 6자 이상이면 예외가 발생합니다.
    - 자동차를 전진하게 하는 `move()` 메서드를 제공합니다.
        - 0 ~ 9 사이의 랜덤 값을 생성합니다.
        - 생성된 값이 4 이상일 경우 전진합니다 (`position++`).
- `Cars`
    - 입력받은 이름 리스트로 자동차 객체들을 생성합니다.
    - 모든 자동차를 순회하며 해당하는 자동차를 전진하게 하는 `moveAll()` 메서드를 제공합니다.

---

### 경주 진행 (RacingController)

- 자동차 이름과 시도 횟수를 입력받아 경주를 시작합니다.
- 각 라운드마다 모든 자동차의 이동 결과를 출력합니다.
- 모든 라운드가 끝나면 우승자를 출력합니다.

---

### 우승자 구하기 (WinnerCalculator)

- 모든 자동차 중 가장 큰 위치(`position`)를 가진 자동차(들)을 찾아, 우승자로 선정합니다.

---

### 출력 (OutputView)

- 라운드별 실행 결과를 출력합니다.
    - 전진은 `-`로 표시합니다.(`pobi : --`)
- 최종 우승자를 출력합니다.
    - 예: `최종 우승자 : pobi, woni`
- 공동 우승자는 쉼표(`,`)로 구분하여 출력합니다.

---

### 예외 처리 및 종료

- 잘못된 값 입력 시 `IllegalArgumentException` 발생 후 프로그램 종료합니다.

---

## 💬 입출력 예시

```
경주할 자동차 이름을 입력하세요.(이름은 쉼표(,) 기준으로 구분)
pobi,woni,jun
시도할 횟수는 몇 회인가요?
3

실행 결과
pobi : -
woni : 
jun : -

pobi : --
woni : -
jun : --

최종 우승자 : pobi, jun
```

---

## 🧠 스스로 정의한 규칙

- 자동차 이름 입력 시 양끝 공백은 글자수에서 제외하되, 사이의 공백은 글자수에 포함시켰습니다.
- 시도 횟수는 자연수 외 입력은 모두 예외처리하였습니다. 양끝 공백은 허용하고, 사이에 공백이 있는 경우 예외처리하였습니다.
